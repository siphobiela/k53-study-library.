# K53 Study Library

Free K53 study materials. Visitors download PDFs and join the WhatsApp Channel.

## Adding PDFs
Upload a PDF to the `docs/` folder using GitHub's Add file → Upload files. Then edit `docs.json` to add its title, description, category and file path. Publish through Settings → Pages → Deploy from branch → main → / (root).

Keep personal email private in GitHub account settings and use GitHub's noreply commit email.
